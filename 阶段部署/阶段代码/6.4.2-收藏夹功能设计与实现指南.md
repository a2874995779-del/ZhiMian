# 6.4.2 收藏夹功能设计与实现指南

> 目标:让用户可以收藏重点题目，后续在收藏夹中按分类、难度、关键词快速复习。

收藏夹和错题本是两个不同的学习入口:错题本由答题行为自动沉淀，收藏夹由用户主动选择。两者可以指向同一张 `question` 表，但不要混成一个状态字段。

## 四、Mapper

### 4.1 `QuestionFavoriteMapper.java`

```java
package com.zhimian.mapper;

import com.zhimian.model.dto.FavoriteQueryDTO;
import com.zhimian.model.vo.FavoriteQuestionVO;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;

import java.util.List;

@Mapper
public interface QuestionFavoriteMapper {
    void insertIgnore(@Param("userId") Long userId, @Param("questionId") Long questionId);

    int deleteByUserAndQuestion(@Param("userId") Long userId, @Param("questionId") Long questionId);

    boolean exists(@Param("userId") Long userId, @Param("questionId") Long questionId);

    long countByUser(@Param("userId") Long userId, @Param("query") FavoriteQueryDTO query);

    List<FavoriteQuestionVO> selectPage(@Param("userId") Long userId,
                                        @Param("query") FavoriteQueryDTO query,
                                        @Param("offset") int offset);
}
```

### 4.2 `QuestionFavoriteMapper.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.zhimian.mapper.QuestionFavoriteMapper">
    <insert id="insertIgnore">
        INSERT IGNORE INTO question_favorite (user_id, question_id)
        VALUES (#{userId}, #{questionId})
    </insert>

    <delete id="deleteByUserAndQuestion">
        DELETE FROM question_favorite
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </delete>

    <select id="exists" resultType="boolean">
        SELECT COUNT(*) > 0
        FROM question_favorite
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </select>

    <sql id="favoriteWhere">
        WHERE f.user_id = #{userId}
          AND q.is_deleted = 0
        <if test="query.categoryId != null">
            AND q.category_id = #{query.categoryId}
        </if>
        <if test="query.difficulty != null">
            AND q.difficulty = #{query.difficulty}
        </if>
        <if test="query.keyword != null and query.keyword != ''">
            AND q.title LIKE CONCAT('%', #{query.keyword}, '%')
        </if>
    </sql>

    <select id="countByUser" resultType="long">
        SELECT COUNT(*)
        FROM question_favorite f
        JOIN question q ON q.id = f.question_id
        <include refid="favoriteWhere"/>
    </select>

    <select id="selectPage" resultType="com.zhimian.model.vo.FavoriteQuestionVO">
        SELECT f.question_id,
               q.title,
               q.difficulty,
               q.category_id,
               c.name AS category_name,
               q.view_count,
               f.create_time AS favorite_time
        FROM question_favorite f
        JOIN question q ON q.id = f.question_id
        LEFT JOIN category c ON c.id = q.category_id
        <include refid="favoriteWhere"/>
        ORDER BY f.create_time DESC
        LIMIT #{offset}, #{query.pageSize}
    </select>
</mapper>
```

### 5.2 `QuestionFavoriteServiceImpl.java`

```java
package com.zhimian.service.impl;

import com.zhimian.common.ErrorCode;
import com.zhimian.common.PageResult;
import com.zhimian.common.UserContext;
import com.zhimian.exception.BusinessException;
import com.zhimian.mapper.QuestionFavoriteMapper;
import com.zhimian.mapper.QuestionMapper;
import com.zhimian.model.dto.FavoriteQueryDTO;
import com.zhimian.model.entity.Question;
import com.zhimian.model.vo.FavoriteQuestionVO;
import com.zhimian.service.QuestionFavoriteService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
@RequiredArgsConstructor
public class QuestionFavoriteServiceImpl implements QuestionFavoriteService {
    private final QuestionFavoriteMapper favoriteMapper;
    private final QuestionMapper questionMapper;

    @Override
    public void add(Long questionId) {
        assertQuestionExists(questionId);
        favoriteMapper.insertIgnore(UserContext.getUserId(), questionId);
    }

    @Override
    public void remove(Long questionId) {
        favoriteMapper.deleteByUserAndQuestion(UserContext.getUserId(), questionId);
    }

    @Override
    public boolean isFavorited(Long questionId) {
        return favoriteMapper.exists(UserContext.getUserId(), questionId);
    }

    @Override
    public PageResult<FavoriteQuestionVO> page(FavoriteQueryDTO query) {
        Long userId = UserContext.getUserId();
        int offset = (query.getPageNum() - 1) * query.getPageSize();
        long total = favoriteMapper.countByUser(userId, query);
        List<FavoriteQuestionVO> records = favoriteMapper.selectPage(userId, query, offset);
        return new PageResult<>(records, total, query.getPageNum(), query.getPageSize());
    }

    private void assertQuestionExists(Long questionId) {
        Question question = questionMapper.selectById(questionId);
        if (question == null) {
            throw new BusinessException(ErrorCode.NOT_FOUND, "题目不存在");
        }
    }
}
```

## 六、Controller

新建 `QuestionFavoriteController.java`:

```java
package com.zhimian.controller;

import com.zhimian.common.PageResult;
import com.zhimian.common.Result;
import com.zhimian.model.dto.FavoriteQueryDTO;
import com.zhimian.model.vo.FavoriteQuestionVO;
import com.zhimian.service.QuestionFavoriteService;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/favorites")
@RequiredArgsConstructor
public class QuestionFavoriteController {
    private final QuestionFavoriteService favoriteService;

    @GetMapping
    public Result<PageResult<FavoriteQuestionVO>> page(@Valid FavoriteQueryDTO query) {
        return Result.success(favoriteService.page(query));
    }

    @PostMapping("/questions/{questionId}")
    public Result<Void> add(@PathVariable Long questionId) {
        favoriteService.add(questionId);
        return Result.success();
    }

    @DeleteMapping("/questions/{questionId}")
    public Result<Void> remove(@PathVariable Long questionId) {
        favoriteService.remove(questionId);
        return Result.success();
    }

    @GetMapping("/questions/{questionId}")
    public Result<Boolean> exists(@PathVariable Long questionId) {
        return Result.success(favoriteService.isFavorited(questionId));
    }
}
```

```text
POST   /api/favorites/questions/{questionId}
DELETE /api/favorites/questions/{questionId}
GET    /api/favorites/questions/{questionId}
```

## 七、题目详情收藏状态

如果希望题目详情抽屉打开时直接知道是否收藏，可以在 `QuestionDetailVO` 加:

```java
private Boolean favorited;
```

然后在 `QuestionServiceImpl.getDetail` 中:

```java
Long userId = UserContext.getUserId();
if (userId != null) {
    vo.setFavorited(questionFavoriteMapper.exists(userId, id));
} else {
    vo.setFavorited(false);
}
```

注意:当前题目详情接口是 `@Public`，未登录用户也能看题目。因此这里不能强制读取登录态；只有有 token 且拦截器放行时才设置收藏状态。更简单的做法是前端打开详情后单独请求 `GET /api/favorites/questions/{id}`，未登录就隐藏收藏按钮。

推荐先采用前端单独请求，后端改动更小。

```ts
import type { PageResult } from './question'
import type { FavoriteQuestionItem } from '../types/favorite'

export interface FavoritePageParams {
  pageNum: number
  pageSize: number
  categoryId?: number
  difficulty?: number
  keyword?: string
}

export function fetchFavorites(params: FavoritePageParams): Promise<PageResult<FavoriteQuestionItem>> {
  return get<PageResult<FavoriteQuestionItem>>('/favorites', { params })

export function addFavorite(questionId: number): Promise<void> {
  return post<void>(`/favorites/questions/${questionId}`)
}

export function removeFavorite(questionId: number): Promise<void> {
  return del<void>(`/favorites/questions/${questionId}`)
}

  return get<boolean>(`/favorites/questions/${questionId}`)
}
```

建议页面能力:

1. 顶部搜索框:按题目标题搜索。
2. 筛选条件:分类、难度。
3. 列表展示:题目标题、难度、分类、浏览量、收藏时间。

列表可以复用 `QuestionCard`，但要注意 `FavoriteQuestionItem` 和 `QuestionListItem` 字段不完全一致。更稳的方式是给收藏夹单独写一个轻量卡片组件。

建议逻辑:

1. 用户未登录:不展示收藏按钮，或点击时弹登录框。

## 十三、自测清单

1. 登录用户。
2. 打开题库任意题目详情。
3. 点击收藏，按钮变为已收藏。
4. 刷新页面后重新打开详情，仍显示已收藏。
5. 进入收藏夹，应看到该题。
6. 在收藏夹取消收藏，列表中移除。
7. 回到题目详情，收藏状态应变为未收藏。
8. 未登录访问 `/favorites`，应被路由守卫拦截并弹登录框。

## 十四、容易踩的坑

1. 收藏接口不要加 `@Public`。
2. 收藏表必须有 `uk_user_question`，否则重复点击会插入多条。
3. 取消收藏应该是幂等的，已经取消再次删除也可以返回成功。
4. 题目被逻辑删除后，收藏列表要过滤掉。
5. 题目详情是公开接口时，不要在未登录场景强行读 `UserContext`。

## 十五、面试可讲点

- 收藏夹是用户主动标记，错题本是行为自动沉淀，两个模型分开更清楚。
- `INSERT IGNORE` 让重复收藏天然幂等。
- 收藏列表以 `user_id + create_time` 索引支撑按收藏时间倒序分页。
- 详情页收藏状态可以前端单独查询，避免污染公开题目详情接口。
