# 6.4.1 错题本功能设计与实现指南

> 目标:补齐刷题闭环中的“错题沉淀”能力。用户答错题目后自动进入错题本，后续可以筛选、复习、标记掌握。

错题本不要只从 `answer_record` 临时查询出来。`answer_record` 是流水记录，适合做统计；错题本是用户的学习状态，应该有独立表维护当前状态、错题次数、最近错误时间和掌握状态。

### 4.2 `WrongQuestionMapper.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.zhimian.mapper.WrongQuestionMapper">
    <insert id="recordWrong">
        INSERT INTO wrong_question (user_id, question_id, wrong_count, status, last_wrong_time)
        VALUES (#{userId}, #{questionId}, 1, 0, NOW())
        ON DUPLICATE KEY UPDATE
            wrong_count = wrong_count + 1,
            status = 0,
            last_wrong_time = NOW(),
            update_time = NOW()
    </insert>

    <update id="recordCorrect">
        UPDATE wrong_question
        SET correct_count = correct_count + 1,
            last_review_time = NOW(),
            update_time = NOW()
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </update>

    <sql id="wrongQuestionWhere">
        WHERE wq.user_id = #{userId}
        <if test="query.status != null">
            AND wq.status = #{query.status}
        </if>
        <if test="query.categoryId != null">
            AND q.category_id = #{query.categoryId}
        </if>
        <if test="query.keyword != null and query.keyword != ''">
            AND q.title LIKE CONCAT('%', #{query.keyword}, '%')
        </if>
    </sql>

    <select id="countByUser" resultType="long">
        SELECT COUNT(*)
        FROM wrong_question wq
        JOIN question q ON q.id = wq.question_id AND q.is_deleted = 0
        <include refid="wrongQuestionWhere"/>
    </select>

    <select id="selectPage" resultType="com.zhimian.model.vo.WrongQuestionVO">
        SELECT wq.id,
               wq.question_id,
               q.title,
               q.difficulty,
               q.category_id,
               c.name AS category_name,
               wq.wrong_count,
               wq.correct_count,
               wq.status,
               wq.last_wrong_time,
               wq.last_review_time
        FROM wrong_question wq
        JOIN question q ON q.id = wq.question_id AND q.is_deleted = 0
        LEFT JOIN category c ON c.id = q.category_id
        <include refid="wrongQuestionWhere"/>
        ORDER BY wq.status ASC, wq.last_wrong_time DESC
        LIMIT #{offset}, #{query.pageSize}
    </select>

    <update id="markMastered">
        UPDATE wrong_question
        SET status = 1,
            last_review_time = NOW(),
            update_time = NOW()
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </update>

    <update id="markUnmastered">
        UPDATE wrong_question
        SET status = 0,
            update_time = NOW()
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </update>

    <delete id="deleteByUserAndQuestion">
        DELETE FROM wrong_question
        WHERE user_id = #{userId}
          AND question_id = #{questionId}
    </delete>
</mapper>
```

### 5.2 `WrongQuestionServiceImpl.java`

```java
package com.zhimian.service.impl;

import com.zhimian.common.ErrorCode;
import com.zhimian.common.PageResult;
import com.zhimian.common.UserContext;
import com.zhimian.exception.BusinessException;
import com.zhimian.mapper.QuestionMapper;
import com.zhimian.mapper.WrongQuestionMapper;
import com.zhimian.model.dto.WrongQuestionQueryDTO;
import com.zhimian.model.entity.Question;
import com.zhimian.model.vo.WrongQuestionVO;
import com.zhimian.service.WrongQuestionService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
@RequiredArgsConstructor
public class WrongQuestionServiceImpl implements WrongQuestionService {
    private final WrongQuestionMapper wrongQuestionMapper;
    private final QuestionMapper questionMapper;

    @Override
    public void recordAnswer(Long questionId, Integer result) {
        Long userId = UserContext.getUserId();
        if (result != null && result == 0) {
            wrongQuestionMapper.recordWrong(userId, questionId);
        } else if (result != null && result == 1) {
            wrongQuestionMapper.recordCorrect(userId, questionId);
        }
    }

    @Override
    public PageResult<WrongQuestionVO> page(WrongQuestionQueryDTO query) {
        Long userId = UserContext.getUserId();
        int offset = (query.getPageNum() - 1) * query.getPageSize();
        long total = wrongQuestionMapper.countByUser(userId, query);
        List<WrongQuestionVO> records = wrongQuestionMapper.selectPage(userId, query, offset);
        return new PageResult<>(records, total, query.getPageNum(), query.getPageSize());
    }

    @Override
    public void markMastered(Long questionId) {
        assertQuestionExists(questionId);
        wrongQuestionMapper.markMastered(UserContext.getUserId(), questionId);
    }

    @Override
    public void markUnmastered(Long questionId) {
        assertQuestionExists(questionId);
        wrongQuestionMapper.markUnmastered(UserContext.getUserId(), questionId);
    }

    @Override
    public void remove(Long questionId) {
        wrongQuestionMapper.deleteByUserAndQuestion(UserContext.getUserId(), questionId);
    }

    private void assertQuestionExists(Long questionId) {
        Question question = questionMapper.selectById(questionId);
        if (question == null) {
            throw new BusinessException(ErrorCode.NOT_FOUND, "题目不存在");
        }
    }
}
```

## 七、Controller

新建 `WrongQuestionController.java`:

```java
package com.zhimian.controller;

import com.zhimian.common.PageResult;
import com.zhimian.common.Result;
import com.zhimian.model.dto.WrongQuestionQueryDTO;
import com.zhimian.model.vo.WrongQuestionVO;
import com.zhimian.service.WrongQuestionService;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/wrong-questions")
@RequiredArgsConstructor
public class WrongQuestionController {
    private final WrongQuestionService wrongQuestionService;

    @GetMapping
    public Result<PageResult<WrongQuestionVO>> page(@Valid WrongQuestionQueryDTO query) {
        return Result.success(wrongQuestionService.page(query));
    }

    @PutMapping("/{questionId}/mastered")
    public Result<Void> markMastered(@PathVariable Long questionId) {
        wrongQuestionService.markMastered(questionId);
        return Result.success();
    }

    @PutMapping("/{questionId}/unmastered")
    public Result<Void> markUnmastered(@PathVariable Long questionId) {
        wrongQuestionService.markUnmastered(questionId);
        return Result.success();
    }

    @DeleteMapping("/{questionId}")
    public Result<Void> remove(@PathVariable Long questionId) {
        wrongQuestionService.remove(questionId);
        return Result.success();
    }
}
```

## 十二、自测清单

1. 登录用户。
2. 进入题库，任选一道题提交“答错”。
3. 进入错题本，应看到该题。
4. 同一道题再次答错，`wrong_count` 应加 1。
5. 对错题提交“答对”，`correct_count` 应加 1。
6. 点击“标记掌握”，状态变为已掌握。
7. 切换“已掌握”筛选，应能看到该题。
8. 点击“移出错题本”，列表中不再出现。

## 十三、容易踩的坑

1. 不要把错题本完全等同于答题流水，否则“标记掌握”很难表达。
2. `wrong_question` 必须有 `uk_user_question`，否则同一用户同一题会产生多条当前状态。
3. 答对题目不一定要自动移出错题本，否则用户缺少复习确认动作。
4. 管理员删除题目后，错题本查询要过滤 `q.is_deleted = 0`。
5. 错题本接口都必须登录，不能加 `@Public`。

## 十四、面试可讲点

- 错题本用状态表承载当前学习状态，答题记录用流水表承载历史统计。
- `ON DUPLICATE KEY UPDATE` 可以让“重复答错”天然幂等累加。
- 标记掌握是用户主动行为，比一次答对就移出错题本更符合学习产品逻辑。
- 查询使用 `user_id + status + last_wrong_time` 索引，支撑个人错题列表分页。
