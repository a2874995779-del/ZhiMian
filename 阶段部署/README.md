# 阶段部署 · 使用说明

本文件夹存放每个开发任务的**实现讲解文档**,由导师(Claude)按需生成,不直接写入项目源码。

## 约定

1. **一个任务一个文件**,命名 = 任务编号 + 任务名,例如:
   - `任务1.1-用户注册接口.md`
   - `任务2.4-SSE流式输出.md`
2. 每个文档的内容结构:
   - 涉及的文件清单(要新建/修改哪些类)
   - 分步实现代码(带中文注释和关键行讲解)
   - 自测清单(对应开发文档里的验收标准)
3. **代码由学员自己敲进项目**,不允许整段复制粘贴——敲的过程就是学习过程,敲完发给导师 review。
4. 任务编号与 `docs/backend-dev-guide.md` 第 5 节的任务清单一一对应。

## 与协作规则的关系

- 默认流程仍然是:学员先自己写 → 导师 review。
- 本文件夹的文档在两种情况下生成:
  - 学员卡住超过两次提示后,导师给参考实现;
  - 学员主动要求"引导我写这个任务"。
